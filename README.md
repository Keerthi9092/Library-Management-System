# Library Management System

## Description
A simple Library Management System developed using Python and Tkinter. This project provides a graphical user interface to manage books, search for book details, and perform book issuing and returning operations.

The application uses Python lists and dictionaries for temporary data storage and does not require a database.

## Features
- Add new books
- Delete books
- Search books by title or ID
- Display all available books
- Issue books
- Return books
- User-friendly graphical interface

## Technologies Used
- Python
- Tkinter
- Python Lists and Dictionaries

## Requirements
- Python 3.x
- Tkinter (included with most Python installations)

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open the Python file in IDLE.
4. Press **F5** or select **Run → Run Module**.

## Note
Book records are stored temporarily in memory. All data will be lost when the application is closed.

## Project Purpose
This project was developed to practice Python programming, GUI development using Tkinter, and basic library management operations.
